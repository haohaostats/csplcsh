# csplcsh 0.1.0

* Initial implementation of CSPL-CSH for right-censored competing risks.
* Locally increment-preserving uniform-kernel baselines and integrated hazards.
* Cause-specific Cox fitting with Breslow ties and coherent survival/density prediction.
* Joint held-out scores, cause decomposition and repeated paired cross-validation.
* Function documentation, runnable examples, numerical regression tests and R CMD check workflow.
